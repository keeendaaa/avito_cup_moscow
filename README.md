# Авито Вместе

Учебный интерактивный прототип для кейс-чемпионата. Не официальный продукт Авито.

## Запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
cd /Users/kenda/avito-vmeste
npm start
```

Открыть http://127.0.0.1:4173. Другой порт: `PORT=4174 npm start`.

## Что можно проверить

1. Профиль → изменить имя и уникальный @юзернейм. Друзья → поиск, подписка на Иру (взаимная) или Артёма (односторонняя). Клик по карточке человека открывает его профиль: общие круги, находки, которые он рекомендует, и подписка. Кнопка «Назад к друзьям» возвращает в список.
2. Вместе → создать круг, пригласить участников, создать подборку. Кнопка «Создать совместную подборку» позволяет автоматически создать круг и чат.
3. Добавлять объявления через «Найти ещё» или общую выдачу. Настраивать сохранённый поиск, видеть действия участников.
4. «Обсудить» у объявления → комментарий с цитатой появляется в чате круга и обсуждении подборки.
5. «Хочу такое же» у недоступного объявления → лист ожидания → «Демо: вариант снова доступен» → уведомление для участников.
6. «Выбрать вместе» → три разных места. Переключение участника явно обозначено как деморежим. Рейтинг: 3/2/1 балл; совпадение — два и более участников включили вариант в топ.
7. В результатах выбрать вариант → разделить счёт → демонстрация оплаты своей доли. Реальных списаний нет.
8. «Задача решена» → архив. Подборку можно просмотреть и восстановить.
9. У каждой карточки есть краткое описание, а в диалоге — полный текст объявления: люди вместе читают условия и правила. У каждого объявления — галерея из 6–8 оригинальных фотографий: листается стрелками, миниатюрами, клавишами ← → и свайпом. Счётчик показывает текущий кадр.
10. Мобильная навигация: «Круги», «Чаты», «Друзья», «Профиль». Раздел «Чаты» — отдельный список переписок всех кругов: чат открывается сразу, без захода в подборку. Поиск объявлений доступен ссылкой «Найти объявления» на экране кругов и в левом меню на desktop.
11. Сценарии идеи: «На выходные» (дома и отель на двоих), «Наш дом» (мебель), «День рождения Маши» (фотограф и подарок), «Своя квартира» и «Новая машина» — дорогие покупки, «Кофейня» — готовый бизнес. Каталог фильтруется по типу: жильё, недвижимость, авто, товары, услуги, бизнес.

## Проверки

```sh
npm run check
npm test
```

Модель и регрессионные тесты — `model.mjs`, `tests/model.test.mjs`. Приложение — `app.js`, адаптивные стили — `styles.css`. Сервер без внешних зависимостей — `server.mjs`.

## Ограничения

Пользователи, круги, голоса, комментарии и оплата демонстрационные. Восемь карточек — это реальные публичные объявления Авито (шесть домов посуточно, диван и услуга фотографа): названия, цены, адреса и первые фотографии взяты с их страниц, у каждой карточки есть ссылка «Открыть на Авито». Цены и доступность — снимок на 1 ноября 2026; на стороне Авито они могли измениться. Оценки и отзывы продавцов не выдумывались: рейтингов в интерфейсе нет, социальные пометки («друг добавил», лист ожидания, бронь) относятся к демослою прототипа и подписаны как демо. Данные сохраняются в localStorage текущего браузера. Нет регистрации на сервере, многопользовательской синхронизации, реальной проверки доступности, внешнего поиска, отправки приглашений, push-уведомлений, бронирования или платёжного партнёра. Регион сохраняется как параметр, но выдача ограничена локальным набором. Для сброса демоданных удалить ключ `avito-vmeste-v1` в localStorage.

Оригинальные публичные файлы Avito Sans загружены с `www.avito.st/s/common/assets/fonts/avito-sans/`. Фирменные цвета взяты с сайта Авито. Логотип — точный SVG, предоставленный пользователем (`assets/avito-logo.svg`); favicon использует контуры его четырёхцветного знака. Оригинальные иллюстрации категорий (чемодан, кресло и валик) извлечены из публичного HTML главной страницы Авито и загружены с `avito.st`. Описания и фотографии объявлений сняты с их публичных страниц на Авито 1 ноября 2026; `tools/build-gallery.mjs` собирает список кадров в `assets/listings/manifest.mjs`. Авито ограничивает автоматический доступ к страницам объявлений, поэтому галереи заполнены по мере доступности: там, где фотографий скачать не удалось, карточка показывает заглушку «Фото в объявлении» и ссылку на исходное объявление. Аватары участников — Unsplash. URL всех материалов и страниц-источников зафиксированы в `assets/sources.json`.

### Анимации

GSAP 3.15.0 сохранён локально в `assets/vendor/gsap.min.js`, поэтому анимациям не требуется CDN или установка npm-зависимостей. Лицензия указана в `assets/vendor/NOTICE.md`.

`motion.js` отвечает за короткие переходы между кругами и разделами, появление карточек, FLIP-перестановку при сортировке, открытие и закрытие диалогов, новые сообщения, отклик кнопок, избранного и фотографий. Эффекты не зациклены, старые GSAP-контексты очищаются при замене DOM. Логотип не анимируется.

При `prefers-reduced-motion: reduce` перемещения и масштабирование заменяются короткими изменениями прозрачности. Изменение системной настройки учитывается без перезагрузки страницы. Браузерные проверки находятся в `tests/browser-qa.mjs` и требуют отдельного Chrome с CDP на порту 9237.

### Дизайн-направление

По запросу пользователя применены принципы [unslop — Damir Sokolovsky (@heydamir)](https://github.com/heydamir/unslop), CC BY 4.0, и playbooks `distill` / `quieter` из [Impeccable — Paul Bakaus](https://github.com/pbakaus/impeccable). Инструменты не устанавливались глобально, внешняя генерация изображений не использовалась.

Убраны дублирующие списки кругов, трёхэтажная шапка каталога, постоянно открытая боковая переписка и декоративные эмодзи. На desktop круги находятся слева, а подборка открыта в основной области. На мобильном сначала показываются круги с оригинальными иллюстрациями Авито; переход к подборке и назад выполняется отдельным шагом, основные разделы доступны в нижней навигации. Обсуждение открывается по действию. Avito Sans, оригинальный SVG пользователя и фирменные цвета сохранены.
